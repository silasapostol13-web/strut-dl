Which browser escape works?

We know Instagram blocks the App Store scheme but allowed Chrome's. So the escape has to go through a browser. The question is which browsers Instagram will let us open — Safari is the one that matters, because every iPhone has it.

  1. Tap each button, top to bottom
  2. If a browser or the App Store opens, come straight back to Instagram
  3. The mark on the right fills in — ✓ opened, ✗ blocked
  4. Then hit Copy results and paste it to Claude
